Functional API
==============

.. warning::
   The DALI TorchVision API is an experimental feature and is subject to change.

The functional API exposes stateless functions that mirror
:mod:`torchvision.transforms.v2.functional`. No operator objects or ``Compose`` wrapper are needed.
